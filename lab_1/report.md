# Звіт з лабораторної роботи №1

**Дисципліна:** WEB-програмування  

**Тема:** Імплементація блогу «Мої 3 найкращі міста світу». Розміщення проєкту в репозиторії GitHub  

**Студентка:** Юлія Гащук  


## 1. Мета роботи

Ознайомитися зі структурою HTML-документа, навчитися використовувати семантичні HTML-теги для створення багатосторінкового статичного сайту, організувати навігацію за допомогою відносних URL-шляхів, підключати зображення та створювати HTML-форми. Опанувати навички роботи з системою контролю версій Git та публікації сайту через GitHub Pages.

## 2. Що було реалізовано

- Створено структуру проєктів з головним файлом `index.html` у корені та окремою папкою `lab_1` для першої лабораторної роботи.
- Розроблено статичний багатосторінковий блог про 3 міста (Львів, Відень, Париж).
- Використано семантичні HTML-теги (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Реалізовано навігацію між сторінками за допомогою відносних посилань.
- Підключено зображення для кожного міста з каталогу `./images/`.
- Створено окрему HTML-форму `form.html` з різними елементами керування (`input`, `label`, `select`, `textarea`, `button`).
- Проєкт опубліковано за допомогою сервісу **GitHub Pages**.

## 3. Результат роботи

Сайт опубліковано та доступно для перегляду у браузері.

Під час виконання лабораторної роботи було закріплено практичні навички створення семантичної HTML-розмітки, проектування структури багатосторінкових web-сайтів, роботи з Git-репозиторієм та розгортання статичних сайтів на GitHub Pages.
